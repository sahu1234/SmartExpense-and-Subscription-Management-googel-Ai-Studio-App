# 🚀 Vibe Code with Sahil: Smart Expense & Subscription Manager

A modern, dark-themed full-stack web application designed to track recurring subscriptions, daily expenses, and manage budgets in Indian Rupees (₹). Built using **Google AI Studio's Build mode**, powered by Gemini, and deployed via Google Cloud Run.

🔗 **Live App Demo:** [https://subtrack-smart-expense-subscription-manager.ai.studio](https://subtrack-smart-expense-subscription-manager.ai.studio)

---

## ✨ Key Features
* **Smart Dashboard:** Real-time calculation of total monthly spend and recurring commitments.
* **Category Tagging:** Organize your expenses and subscriptions by custom categories (Entertainment, Utilities, SaaS, Food, etc.).
* **Budget Vibe Check:** Visual indicators and alerts when spending crosses your custom monthly threshold.
* **Secure Authentication:** Integrated Google Sign-In via Firebase Auth.
* **Cloud Database:** Persistent storage using Firestore so data syncs securely across devices.
* **100% Serverless Deployment:** Deployed instantly to Google Cloud Run.

---

## 🛠️ Built With
* **AI Engine:** Google Gemini (via Google AI Studio)
* **Frontend:** React, Tailwind CSS, Lucide Icons
* **Backend / Auth:** Firebase (Firestore & Authentication)
* **Hosting:** Google Cloud Run
